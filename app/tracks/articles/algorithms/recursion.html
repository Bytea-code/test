بازگشتی فکر کردن: سه سؤال قبل از نوشتن تابع

م مریم کاویانی ۷ آبان ۱۴۰۵ ۸ دقیقه مطالعه

بیشتر آدم‌ها با بازگشت مشکل دارند چون سعی می‌کنند کل درخت فراخوانی را در headشان اجرا کنند. راه درست، فکر کردن قراردادی است: فرض کن فراخوانیِ کوچک‌تر درست کار می‌کند؛ تو فقط یک قدم را بنویس.

سه سؤال

  • حالت پایه چیست؟ کوچک‌ترین ورودی که جوابش بدیهی است.
  • قدم کوچک‌تر چیست؟ چگونه ورودی را به همان حالت نزدیک می‌کنم؟
  • ترکیب چیست؟ جوابِ قدمِ کوچک‌تر را چگونه به جواب فعلی تبدیل می‌کنم؟
function depth(node) {
  if (!node) return 0;              // حالت پایه
  return 1 + Math.max(              // ترکیب
    depth(node.left),               // قدم کوچک‌تر
    depth(node.right)
  );
}

پناهگاه حافظه

هر فراخوانی یک قاب روی پشته می‌گذارد؛ بازگشت عمیق یعنی پشتهٔ عمیق و خطر stack overflow. اگر عمق به اندازهٔ ورودی رشد می‌کند (مثل لیست پیوندی بلند)، نسخهٔ حلقه‌ای یا بازگشت دنباله‌ای (tail) بنویس.

نکتهٔ منتور: بازگشت را اول روی کاغذ با n=3 اجرا کن؛ اگر سه قدم اول درست بود، قرارداد درست است.
