Grid یا Flexbox؛ کدام را کجا استفاده کنیم؟

س سارا احمدی ۱۲ مهر ۱۴۰۵ ۶ دقیقه مطالعه

هر بار که یک چیدمان جدید می‌سازیم، همین سؤال برمی‌گردد: Grid بزنم یا Flex؟ جواب کوتاه این است که Flex برای چیدمان یک‌بعدی است (یک ردیف یا یک ستون) و Grid برای چیدمان دوبعدی (ردیف و ستون با هم). اما جواب کاربردی‌تر این است: از محتوا شروع کن، نه از ابزار.

یک بعد در برابر دو بعد

وقتی آیتم‌ها فقط در یک جهت جریان دارند — مثل نوار ناوبری، ردیف دکمه‌ها یا لیست برچسب‌ها — Flexbox عالی است: اندازه‌ها را بر اساس محتوا تنظیم می‌کند و فاصله‌ها را با gap مدیریت می‌کند. اما وقتی باید هم‌زمان ردیف و ستون را کنترل کنی — مثل گالری کارت‌ها یا چیدمان کل صفحه — Grid به تو اجازه می‌دهد ترک‌ها را یک‌بار تعریف کنی و آیتم‌ها را در نواحی بنشانی.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1.1rem;
}

.toolbar {
  display: flex;
  align-items: center;
  gap: .6rem;
}

قانون سرانگشتی

  • اگر فقط جهت و فاصله مهم است → Flexbox.
  • اگر جای دقیق آیتم در ردیف و ستون مهم است → Grid.
  • اگر ریسپانسیو بدون مدیاکوئری می‌خواهی → Grid با auto-fit و minmax.
  • این دو رقیب نیستند؛ یک صفحهٔ خوب معمولاً هر دو را با هم دارد.
نکتهٔ منتور: گرید را برای «ساختار صفحه» و فلکس را برای «چیدمان داخل کامپوننت» نگه دار؛ این تقسیم کار، کد را خوانا نگه می‌دارد.
